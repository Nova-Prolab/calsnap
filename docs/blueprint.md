# **App Name**: CalSnap

## Core Features:

- Calorie Estimation: AI-powered calorie estimation: Upload a photo of your meal, and the app will estimate its calorie count using AI. The AI will be a tool, giving approximate values of macro nutrients.
- Calorie Dashboard: Dashboard: Displays daily calorie intake, macronutrient breakdown, and remaining calories.
- Gender Selection: Gender Selection: Asks users for gender during onboarding for personalized calorie planning.
- Photo Logging: Photo logging: allows user to take photo and save it, as input for future calorie estimations
- User Profile: User Profile: Basic profile screen to view user information.

## Style Guidelines:

- Primary color: Vibrant orange (#F97316) to convey energy and health.
- Background color: Light gray (#F3F4F6), a slightly desaturated version of the primary, for a clean interface.
- Accent color: Teal (#2DD4BF), analogous to the primary and used for interactive elements and highlights.
- Body and headline font: 'Inter', a sans-serif, providing a modern, objective and neutral appearance.
- Use outline icons from Lucide React for a clean and consistent look.
- Use a card-based layout for meal display and summaries.
- Subtle fade-in animations when transitioning between screens.
